# Security policy

## Supported versions

KnightBus is versioned per package, and fixes go onto the latest released version of the affected
package. If you are on an older major, expect to upgrade to pick up a security fix.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it through GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/BookBeat/knightbus/security/advisories/new) of this repository and
open a draft advisory. That keeps the discussion private until a fix is released.

Include what you have — the affected package and version, what an attacker can do, and a way to
reproduce it. A rough report is more useful than no report.

You can expect an acknowledgement within a few working days. Once a fix is released we will publish
the advisory and credit you, unless you would rather stay anonymous.
